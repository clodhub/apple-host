# Apple host

The apple-host component at version 0.13.0 provides com.clodhub/apple-shell version 1.0.0 to an illustrative application consumer, which in turn supplies com.clodhub/theme version 1.0.0. The 2 arrows each run from a named output to a required input of the same type and version. Setting values shown are placeholders and secrets appear only as references.
